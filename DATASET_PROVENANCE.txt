Data classification and provenance statement
---------------------------------------------

The ecu_demo repository and its logs are included as demonstration/test
fixtures in this software project. They are intended to be synthetic
examples, not production ECU source code, customer data, or operational
vehicle logs. They contain deliberately seeded examples for exercising
analysis behavior.

This statement describes the intended status of the bundled demo fixtures;
it is not independent proof of authorship or ownership. Before external
submission or publication, the project owner must confirm that all bundled
source, log text, identifiers, and example credential-like strings are
original synthetic examples or are otherwise approved for this use. If any
content was copied or adapted from another source, record that source and
its applicable permission here or remove the content.

The coding-guideline file is project guidance, not a copy of the MISRA
standard. Its "approved source" label is present in the file itself, but
formal faculty/organization approval evidence is not bundled here. Attach
the relevant approval record separately if required by the submission
process.

Privacy and handling
--------------------

The demo repository is mounted read-only by the Compose configuration.
Application records, indexes, and generated outputs are stored separately
under the application's data directory/volume. Do not submit generated
databases, secret keys, or real credentials as input data. The source tree
also has a generated local data/ directory; inspect and exclude it from any
submission archive unless the evaluator explicitly requests sanitized
application outputs.
